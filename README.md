# AddressableServerPackage

## 檔案內容說明

WebGL → .bundle的檔案，Addressable素材打包後的資料夾，資料夾名稱需要維持WebGL。Addressable系統中包好的素材內容有更動的話會產生新的bundle檔，因此在進行打包前，需要先清空這個資料夾，確保不會有沒有用到的殘留檔案

WebGL_View → 前端內嵌進網頁的WebGL檔案，Unity端將正式版本直接Build進這個資料夾內上傳即可

https-server README.md → Unity WebGL .bundle的檔案在不同網域下要架設https-server的內容
